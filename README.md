# Vantage — тиснёная голографическая фольга

Страница: https://vantageinc.github.io/holo-foil/

Карточку можно поворачивать мышью или пальцем; справа вверху панель настроек текстуры, цветов и свечения.

Фольгу рисует набор [holospot](https://github.com/dmitrykurash/holospot) Дмитрия Кураша (лицензия MIT,
копия лежит в `vendor/holospot`), сцена собрана на [three.js](https://threejs.org/).
